# Blog Application

A lightweight, modern web blog application built with React, TypeScript, and Vite. Posts and index metadata are loaded dynamically from static JSON structures.

## 🚀 Features

- **React & TypeScript**: Type-safe component architecture with React 19 and TS.
- **Client-Side Routing**: Smooth page navigation using React Router.
- **JSON Post Engine**: Fetches blog posts, indexes, and slug mappings from static JSON files.
- **Sanitized HTML Rendering**: Safely displays formatted blog post content.

## 🛠️ Tech Stack

- **Frontend**: React 19, React Router 7
- **Build Tool**: Vite, TypeScript
- **Utilities**: `sanitize-html`

## 💻 Getting Started

### Installation

```bash
npm install
```

### Development

Start the local development server:

```bash
npm run dev
```

### Build

Compile TypeScript and build for production:

```bash
npm run build
```

### Preview

Preview the production build locally:

```bash
npm run preview
```
