# A Small Blog

A lightweight web blog application built with React, TypeScript, and Vite. Posts and index metadata are loaded dynamically from static JSON structures.

## Link
https://blog.memento-olontic.xyz

## 🛠️ Tech Stack

- **Frontend**: React 19, React Router 7
- **Build Tool**: Vite, TypeScript
- **Utilities**: `sanitize-html`
